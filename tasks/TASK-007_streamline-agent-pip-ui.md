The Agent Pip UI should be implemented as a separate vertical panel on the right side of the window. 
It should behave similarly to the left panel: it has opened and closed states, can be resized horizontally when opened, contains an input field with a send button at the bottom, Pip's icon in a round frame at the very top, and the chat history occupies the remaining vertical space of the chat window between the input and the top icon.
When closed it should be collapsed to an icon without the vertical ribbon. The icon should be in the rightmost position of the top bar.
